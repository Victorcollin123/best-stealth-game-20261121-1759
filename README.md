Make the best stealth game.

Night Post is a top-down stealth game: carry three letters across a walled courtyard at night and reach the green gate unseen. Three guards patrol with raycast vision cones, bushes hide you, lamps give you away, and running feet are loud enough to draw a guard over. Slip past unseen for a Ghost rating, get spotted once for Shadow, twice or more for Seen. WASD or arrows to move, Shift to sneak, P to pause, M to mute, R to restart.

## Run it

```sh
node serve.ts
```
