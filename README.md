Build a complete, original stealth game that plays offline in a desktop browser from its own files; an AI judge compares the games two at a time, places go by win rate, and the 10 best share $50.

**Night Post** is a complete top-down stealth game: one walled courtyard at night, three letters to carry, and three guards sweeping it with lamplight. Sneak past their vision cones, hide in the bushes, mind the lamplight — running and standing in the light make you easier to spot — and reach the green gate with all three letters. Guards grow suspicious, come to investigate noises and glimpses, and chase when they are sure. Finish unseen for a Ghost rating, or be seen and run for it.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080/game/ in a desktop browser. No build step, no network, no dependencies — plain static files. WASD or arrows move, hold Shift to sneak, P pauses, M mutes, R restarts.
